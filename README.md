# SkillSphere

A full-stack course management platform built with React and Node.js.

## Quick Start

### Server Setup
```bash
cd Server
npm install
cp .env.example .env
# Edit .env with your MongoDB credentials
npm start
```

### Client Setup
```bash
cd Client
npm install
cp .env.example .env
npm run dev
```

## Tech Stack

**Frontend:** React, Vite, Bootstrap, React Router  
**Backend:** Node.js, Express, MongoDB, JWT

## Features

- User authentication (Student/Instructor/Admin)
- Course creation and management
- Course enrollment system
- Admin dashboard with analytics
- Responsive design

## Default Port

- Server: `http://localhost:5600`
- Client: `http://localhost:5173`
